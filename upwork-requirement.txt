Summary
We are looking for an experienced AI/LLM Engineer to develop production-ready Retrieval-Augmented Generation (RAG) applications, intelligent AI agents, and automated business workflows.

The ideal candidate should have strong hands-on experience building scalable AI-powered applications using Python, LangChain, LangGraph, OpenAI, Claude, Gemini, vector databases, and automation platforms such as n8n.

Key Responsibilities
1. Design and develop RAG-based applications using LLMs and vector databases.
2. Build intelligent AI agents capable of executing multi-step tasks, calling external APIs, and automating business processes.
3. Implement document ingestion, embeddings, semantic search, hybrid retrieval, and contextual question-answering systems.
4. Develop AI chatbots and knowledge assistants using internal business documents, websites, PDFs, and databases.
5. Create automated workflows using n8n, webhooks, REST APIs, and third-party integrations.
6. Integrate OpenAI, Anthropic Claude, Google Gemini, and other LLM APIs.
7. Build scalable backend services using Python, FastAPI, and asynchronous processing.
8. Implement conversation memory, tool calling, structured outputs, and human-in-the-loop workflows.
9. Improve retrieval accuracy, reduce hallucinations, optimise response latency, and manage API costs.
10. Deploy, monitor, and maintain AI applications using Docker, AWS, and CI/CD pipelines.

Required Technical Skills
- AI/LLMs: OpenAI, Claude, Gemini, prompt engineering, function calling
- RAG Frameworks: LangChain, LangGraph, LlamaIndex
- Vector Databases: Pinecone, Qdrant, FAISS, Weaviate, ChromaDB
- Backend: Python, FastAPI, REST APIs
- AI Automation: n8n, API integrations, webhooks, workflow orchestration
- Databases: PostgreSQL, Redis, MongoDB
- Cloud & DevOps: AWS, Docker, GitHub Actions
- AI Architecture: Multi-agent systems, semantic search, embeddings, document processing

Expected Deliverables
1. A functional RAG application with document ingestion and knowledge-based querying.
2. AI agents capable of executing predefined business tasks and interacting with external services.
3. Automated workflows integrated with relevant business applications and APIs.
4. Secure, scalable backend APIs and deployment configuration.
5. Source code, technical documentation, and deployment instructions.
